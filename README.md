# 💌 Happy Anniversary Envelope Animation

This is a fun and interactive envelope animation project created using **HTML**, **CSS**, and **a bit of JavaScript**. When clicked, the envelope opens up to reveal a heartfelt letter inside!

## 📸 Screenshot

![Screenshot](https://github.com/Priyash-Das/Photos/blob/main/V%20Day%20Card.png)

## ✨ Features

- Stylish animated envelope design
- Floating envelope animation
- Click to open and reveal a message
- Responsive and minimal aesthetic
- Cute heart button with animation

## 🛠️ Technologies Used

- HTML5
- CSS3
